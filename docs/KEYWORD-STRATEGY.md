## 2. Tier 2 — Bare/ambiguous name query (long-term, low near-term probability)

- Walid Hasan
- Walid Hassan

**Rationale:** Currently occupied by Wikipedia entities, LinkedIn/Facebook directory pages, and unrelated individuals. Not abandoned, but treated as a multi-year entity-authority goal rather than a near-term ranking target. Progress here is measured by Knowledge Panel emergence and AI-answer accuracy, not classic SERP position.

## 3. Tier 3 — Service/commercial intent queries (where he competes against many operators, name irrelevant)

Local SEO / web design service queries where "Walid Hasan" the person is not searched, but where ranking content under his byline builds topical authority that feeds entity strength:
- local SEO for [niche] businesses (septic, well drilling, waterproofing — via Inoviqa)
- SEO consultant for SaaS startups
- WordPress Elementor landing page designer
- GA4 server-side tracking setup consultant
- freelance conversion rate optimization expert Bangladesh
- Chrome extension developer for [Shopify admin / RFQ / SEO audit]

**Rationale:** These are Inoviqa/service-page targets more than personal-brand targets, but every article/case study written to rank for them should carry a consistent byline and link back to walidhasan.com, converting commercial SEO traffic into entity-reinforcement traffic.

## 4. Tier 4 — Disambiguation & comparison queries (defensive)

- Walid Hasan vs Squareko
- Walid Hasan Squareko (defensive — should NOT rank for this if it isn't him; monitor it doesn't get miscredited)
- Is Walid Hasan Inoviqa legit / Walid Hasan reviews
- Walid Hasan real name / Walid Hasan Riyad

**Rationale:** Low volume but high-consequence if a namesake's reputation issue or a scam-report page ever ranks for these — worth monitoring, not necessarily targeting with content yet.

## 5. AI-Search / Conversational Query Targets

- "What has Walid Hasan built?"
- "Is Walid Hasan a good SEO consultant?"

- "What Chrome extensions has Walid Hasan made?"
- "Where is Walid Hasan based?"
